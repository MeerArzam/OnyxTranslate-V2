What this test is

Every language in this report was put through a REAL Gemini round-trip using the exact production pipeline — not a mock, not a static simulation:

  1. Exact production system prompt — buildSystemPrompt() from convex/translateContent.ts: all 23 phases (P1 glossary fidelity → P23 final proofread), per-language dialogue marks, profanity map, rank map, magic-system note, formality system, style sheet, locked glossary column, and name map.
  2. Bible Pass glossary lock — applyBiblePassServer() wraps locked terms in placeholders before Gemini sees the text; postProcessTranslationForTest() restores them, so Signet/Venin/Wards/Empyrean and friends can never be re-translated ad hoc.
  3. Same Gemini endpoint & 5-key rotation — native generateContent API, thinkingBudget: 0, 3 attempts per key, 429/5xx backoff.
  4. Same post-processing — placeholder restore, dictionary-format normalization, meta-commentary stripping, paragraph-label stripping, cultural filters, dragon-telepathy formatting, RTL marker insertion.
  5. Full 23-phase QA engine — runQA() from src/lib/translator/qa.ts, plus P2 locked-name spot checks (Violet / Xaden / Aretia) and P8 script/RTL verification.

Locked test sentence (identical for all 20 markets):

Violet wakes up in Aretia confused, with a ring and a note from Xaden: "Don't look for me."
She realizes she is married, but her husband is lost in the dark.
